# Licznik pojazdów

Prosta aplikacja Android do zliczania:
- samochodów osobowych,
- ciężarówek,
- autobusów.

Funkcje:
- liczniki pojazdów,
- historia kliknięć z godziną,
- automatyczny zapis danych,
- reset liczników,
- tryb jasny/ciemny,
- zmiana koloru tła,
- zmiana koloru przycisków.

Package: `com.example.vehiclecounter`

## Uruchomienie

Otwórz folder projektu w Android Studio i wykonaj Gradle Sync.

Projekt korzysta z Java 17.
